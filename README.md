# Whose Turn?

An Android app for sharing household chores. Each chore has its own participant order. When someone marks a chore as done, the turn moves to the next person. After the last person, the order starts again.

## Features

- See who is responsible for each chore and their position in the rotation.
- Mark a chore as done to pass the turn to the next participant.
- See who completed each chore most recently.
- Choose who takes part in each chore and in what order; a new chore starts with the least busy person.
- Set how often a chore repeats; the list is sorted by due date and shows overdue chores.
